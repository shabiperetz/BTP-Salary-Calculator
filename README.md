# סימולטור שכר בסיסי כבאי בט"פ

**ארגון העובדים · מערך הכבאות בישראל**

מחשבון שכר **ברוטו** חודשי לכבאי בטיחות ומניעת שריפות, לפי שכר בסיס, ותק ותפקיד.

קובץ HTML בודד, ללא תלויות וללא שרת — נפתח בכל דפדפן, גם במצב לא מקוון.

**אתר חי:** https://shabiperetz.github.io/BTP-Salary-Calculator/

## מודל החישוב

| שלב | נוסחה |
|---|---|
| מקדם ותק | `1.01^min(שנים,29) × 1.0075^max(0,שנים−29)` |
| שכר בסיס מעודכן | `שכר בסיס × מקדם ותק` |
| תוספת מתמיד | `שכר בסיס מעודכן × 2%` — החל מ־18 שנות ותק |
| תוספת תפקיד | `שכר בסיס מעודכן × אחוז התפקיד` |
| שכר משולב | `מעודכן + מתמיד + תפקיד` |
| ערך שעה | `שכר משולב ÷ 173.3` |
| תוספת משמרות | `ערך שעה × 191` |
| **סך ברוטו** | `שכר משולב + תוספת משמרות` |

תוספת מתמיד ותוספת תפקיד הן **שתי תוספות מקבילות על אותו בסיס** — אין הצטברות
ביניהן. אחוז התפקיד אינו מחושב על סכום שכבר כולל את המתמיד.

### אחוזי תפקיד

| תפקיד | תוספת |
|---|---|
| לוחם אש | 0% |
| סגן מפקד צוות | 4% |
| מפקד צוות | 9% |
| סגן מפקד משמרת ומקביליו | 15% |
| מפקד משמרת | 20% |

### שעות משמרת

**191 שעות חודשיות**, קבוע. זהו ממוצע שנתי שחושב על פני כל חודשי השנה, כולל
חודשים שיש בהם חגים. המודל הקודם, שגזר את השעות מהיום שבו נפתח החודש, הוחלף
בממוצע הזה.

## קרן השתלמות

מחושבת על **השכר המשולב בלבד** — תוספת המשמרות אינה מבוטחת:

| רכיב | שיעור |
|---|---|
| הפרשת עובד | 2.5% |
| הפרשת מעסיק | 7.5% |
| **סך ההפרשה** | **10%** |

אינה חלק מהברוטו: חלק העובד יורד מהשכר וחלק המעסיק נוסף מעליו. כל רכיב מעוגל
לאגורות והסך נגזר מהרכיבים המעוגלים, כדי שהמוצג תמיד יסתכם.

## מגבלות ידועות

- **ברוטו בלבד** — ללא מס הכנסה, ביטוח לאומי, מס בריאות והפרשות פנסיה.
- שעות המשמרת הן ממוצע קבוע; חודש בודד יכול לסטות ממנו.
- אין רכיבי כוננות, שעות נוספות מעבר לגלגל, ביגוד, הבראה, נסיעות או תוספת משפחה.

## פיתוח

`index.html` הוא המקור היחיד. `share.html` נגזר ממנו אוטומטית:

```bash
node build-share.js
```

### לוגו

הסמל מוטמע ב־`index.html` כ־data URI, כדי שהקובץ יישאר עצמאי ויעבוד גם ללא
אינטרנט. המקורות שמורים ב־`assets/`:

- `assets/logo-original.jpg` — הלוגו המלא כפי שהתקבל (1080×1109)
- `assets/emblem.png` — הסמל בלבד, חתוך, 200×200, רקע שקוף — זה מה שמוטמע

הכיתוב "ארגון העובדים / מערך הכבאות בישראל" מוצג כטקסט HTML ולא כחלק מהתמונה,
כדי שיישאר קריא בכל גודל מסך.
