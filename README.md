# סימולטור שכר בסיסי כבאי בט"פ

**ארגון העובדים · מערך הכבאות בישראל**

מחשבון שכר **ברוטו** חודשי לכבאי בטיחות ומניעת שריפות, לפי שכר בסיס, ותק ותפקיד.

קובץ HTML בודד, ללא תלויות וללא שרת — נפתח בכל דפדפן, גם במצב לא מקוון.

**אתר חי:** https://shabiperetz.github.io/BTP-Salary-Calculator/

## מודל החישוב

| שלב | נוסחה |
|---|---|
| מקדם ותק | `1.01^min(שנים,29) × 1.0075^max(0,שנים−29)` |
| שכר בסיס מעודכן | `שכר בסיס × מקדם ותק` |
| תוספת מתמיד | `שכר בסיס מעודכן × 2%` — החל מ־18 שנות ותק |
| תוספת תפקיד | `שכר בסיס מעודכן × אחוז התפקיד` |
| שכר משולב | `מעודכן + מתמיד + תפקיד` |
| ערך שעה | `שכר משולב ÷ 173.3` |
| תוספת משמרות | `ערך שעה × 191` |
| **סך ברוטו** | `שכר משולב + תוספת משמרות` |

תוספת מתמיד ותוספת תפקיד הן **שתי תוספות מקבילות על אותו בסיס** — אין הצטברות
ביניהן. אחוז התפקיד אינו מחושב על סכום שכבר כולל את המתמיד.

### אחוזי תפקיד

| תפקיד | תוספת |
|---|---|
| לוחם אש | 0% |
| סגן מפקד צוות | 4% |
| מפקד צוות | 9% |
| סגן מפקד משמרת ומקביליו | 15% |
| מפקד משמרת | 20% |

### שעות משמרת

**191 שעות חודשיות**, קבוע. זהו ממוצע שנתי שחושב על פני כל חודשי השנה, כולל
חודשים שיש בהם חגים. המודל הקודם, שגזר את השעות מהיום שבו נפתח החודש, הוחלף
בממוצע הזה.

## קרן השתלמות

מחושבת על **השכר המשולב בלבד** — תוספת המשמרות אינה מבוטחת:

| רכיב | שיעור |
|---|---|
| הפרשת עובד | 2.5% |
| הפרשת מעסיק | 7.5% |
| **סך ההפרשה** | **10%** |

אינה חלק מהברוטו: חלק העובד יורד מהשכר וחלק המעסיק נוסף מעליו. כל רכיב מעוגל
לאגורות והסך נגזר מהרכיבים המעוגלים, כדי שהמוצג תמיד יסתכם.

## סימולטור מעבר לעבודת יום — `day-transition.html`

קובץ עצמאי שני, לכבאי **דור ב׳ (דור ביניים)** ו**דור ג׳** העוברים מעבודת משמרות
לעבודת יום. מנוע נפרד לגמרי — אין לו תלות במחשבון השכר הבסיסי.

| שלב | נוסחה |
|---|---|
| שכר קובע | קלט ידני, לפי התלוש |
| תוספת ק.ד (דור ב׳ בלבד) | 450 ₪ בד״א במשמרת · 550 ₪ קצין במשמרת |
| שכר קובע כולל ק.ד | `שכר קובע + תוספת ק.ד` |
| תוספת עבודת יום | `שכר קובע כולל ק.ד × 40%` |
| שכר קובע בעבודת יום | `שכר קובע כולל ק.ד + 40%` |
| תוספת ״גחלת״ | `שכר קובע בעבודת יום × שיעור מלוא התוספת` |
| **אומדן שכר בעבודת יום** | `שכר קובע בעבודת יום + גחלת` |

### שיעור מלוא התוספת (״גחלת״) — הסכם קיבוצי 2026, שימור משמרות

| רמת תפקיד (נספח ב׳) | דור ב׳ (ביניים) | דור ג׳ |
|---|---|---|
| רמה 1 | 64.95% | 39.50% |
| רמה 2 | 50.29% | 27.50% |
| רמה 3 | 31.96% | 11.00% |
| רמה 4 | 24.63% | 5.00% |

רמה 4 חלה גם על **כל תפקיד שאינו מצוין בנספח ב׳** המבוצע על ידי כבאי שעבר לעבודת
יום עקב פציעה.

תוספת ק.ד (הסכם 2026) קיימת ל**דור ב׳ בלבד**, ומעלה את השכר הקובע עצמו — כל שאר
החישובים (40% ותוספת הגחלת) נגזרים מהשכר הקובע כולל הק.ד.

**עלייה ברמה מעלה את אחוז השימור בהתאמה** — עובד שמתקדם לרמת תפקיד גבוהה יותר זכאי
לשיעור התוספת של אותה רמה.

**שכר קובע לכבאי בט״פ** — השכר הקובע במשכורת האחרונה לפני המעבר, הכולל את תוספת
הפיקוד ואת תוספת המתמיד, ובתנאי שהעובד קיבל אותן במשך שנתיים.

**תנאי סף לקבלת הגחלת: ביצוע 13 שעות מחושבות.** שעות מחושבות הן שעות נוספות
משוקללות לפי שיעורן — למשל `20 × 125% + 10 × 150% = 40`.

רשימת התפקידים המוצגת בממשק לכל רמה היא **דוגמה בלבד**; הרשימה המחייבת היא נספח ב׳.

### קרן השתלמות בסימולטור המעבר

10% (2.5% עובד + 7.5% מעסיק) על **השכר הקובע בעבודת יום** — כלומר אחרי תוספת ה־40%
ולפני תוספת הגחלת.

## מגבלות ידועות

- **ברוטו בלבד** — ללא מס הכנסה, ביטוח לאומי, מס בריאות והפרשות פנסיה.
- שעות המשמרת הן ממוצע קבוע; חודש בודד יכול לסטות ממנו.
- אין רכיבי כוננות, שעות נוספות מעבר לגלגל, ביגוד, הבראה, נסיעות או תוספת משפחה.

## פיתוח

שני קבצי מקור עצמאיים, כל אחד HTML בודד ללא תלויות:

- `index.html` — סימולטור השכר הבסיסי (משמרות)
- `day-transition.html` — סימולטור המעבר לעבודת יום

`share.html` — גרסת הארטיפקט — נגזרת מ־`index.html` אוטומטית. הקישור שבה
לסימולטור המעבר ליום מומר בבנייה לכתובת מוחלטת, כי בארטיפקט אין קבצים אחיים:

```bash
node build-share.js
```

### לוגו

הסמל מוטמע בשני קבצי המקור כ־data URI, כדי שיישארו עצמאיים ויעבדו גם ללא
אינטרנט. המקורות שמורים ב־`assets/`:

- `assets/logo-original.jpg` — הלוגו המלא כפי שהתקבל (1080×1109)
- `assets/emblem.png` — הסמל בלבד, חתוך, 200×200, רקע שקוף — זה מה שמוטמע
- `assets/og.jpg` — תמונת ה-OG של `index.html`
- `assets/og-day.png` — תמונת ה-OG של `day-transition.html`, נוצרת מ־`emblem.png`:

```bash
node build-og.js
```

תמונת ה-OG של עמוד המעבר היא הגרדיאנט של כרטיס ההירו עם הסמל במרכז, בלי טקסט:
הכותרת והתיאור מגיעים ממטא-תגיות `og` ומוצגים כטקסט לצד התמונה, כך שהתמונה
לא נושאת שם מוצר שעלול להיות שגוי לעמוד שהיא מייצגת.

הכיתוב "ארגון העובדים / מערך הכבאות בישראל" מוצג כטקסט HTML ולא כחלק מהתמונה,
כדי שיישאר קריא בכל גודל מסך.
