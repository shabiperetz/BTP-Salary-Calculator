# סימולטור שכר כבאי

מחשבון שכר **ברוטו** חודשי לכבאי בטיחות ומניעת שריפות, לפי ותק, תפקיד ויום תחילת החודש בגלגל המשמרות.

קובץ HTML בודד, ללא תלויות וללא שרת — נפתח בכל דפדפן, גם במצב לא מקוון.

## מודל החישוב

| שלב | נוסחה |
|---|---|
| מקדם ותק | `1.01^min(שנים,29) × 1.0075^max(0,שנים−29)` |
| תוספת מתמיד | `× 1.02` החל מ־18 שנות ותק |
| שכר בסיס מעודכן | `בסיס × מקדם ותק × מתמיד` |
| תוספת תפקיד | `בסיס מעודכן × אחוז התפקיד` |
| שכר משולב | `בסיס מעודכן + תוספת תפקיד` |
| ערך שעה | `שכר משולב ÷ 173.3` |
| תוספת גלגל | `ערך שעה × שעות גלגל` |
| **סך ברוטו** | `שכר משולב + תוספת גלגל` |

## מגבלות ידועות

- **ברוטו בלבד** — ללא מס הכנסה, ביטוח לאומי, מס בריאות והפרשות פנסיה.
- שעות הגלגל מחושבות כולן בתעריף שעה בסיסי (100%), ללא פיצול ל־125%/150%, לילה או שבת וחג.
- טבלת שעות הגלגל תלויה ביום פתיחת החודש בלבד ואינה מתחשבת באורך החודש (28/29/30/31 ימים).
- אין רכיבי כוננות, שעות נוספות, ביגוד, הבראה, נסיעות או תוספת משפחה.
